# アルゴリズム解説: 点群抽出と最適化

## 1. KD-Tree によるノイズ除去の最適化
数億点規模の点群データを効率的に扱うため、空間分割データ構造であるKD-Treeを採用しました。
- 目的: 統計的な外れ値（ノイズ）の高速な探索と除去。
- 効果: 全探索と比較し、近傍探索の計算量を$O(N)$から$O(\log N)$へと削減。

## 2. RANSAC による高精度平面抽出
非構造的な点群から建築外壁（平面）を抽出するためにRANSAC(Random Sample Consensus)を使用しています。
- 精度管理: 距離閾値を 5mm に設定し、反復計算を行うことで、現場実測値との誤差 ±5mm 以内を達成。
- 幾何学的特徴の抽出: 平面方程式 $ax + by + cz + d = 0$ を導出し、これをベクトルデータ（CAD）の基盤として利用。
