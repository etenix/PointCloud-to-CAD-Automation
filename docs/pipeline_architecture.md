# システムアーキテクチャ

## 処理フロー
1. データ入力: レーザースキャナーより取得した大容量点群（LAS/PCD形式）。
2. 並列処理 (Multiprocessing): 
   - 複数のスキャンポイントからのデータを並列で配准（Registration）。
   - CPUのコア数に応じたプロセス分割により、処理時間を大幅に短縮。
3. セマンティックマッピング:
   - 抽出された幾何形状に「外壁」「開口部」などの属性情報を付与。
4. CAD自動生成:
   - `ezdxf`を介して、レイヤー構造を維持したままDXF形式へ出力。

## 導入成果
- 工数削減: 従来の手動トレース作業と比較し、約50%の工数削減を実現。
- 自動化範囲: 点群のクリーニングからCAD出力までの80%を自動化。
