# PointCloud to CAD Automation

## 概要
3D点群データから建築外壁面を自動抽出し、CAD（DXF）形式へ変換するパイプライン。  
設計・測量業務の効率化を目的とする。

---

## 使用技術
- Python
- Point Cloud処理
- RANSACアルゴリズム
- DXF（AutoCADフォーマット）

---

## 主な機能
- 点群データの前処理
- RANSACによる平面抽出
- 外壁面の自動識別
- DXF形式への変換

---

## 工夫点
- ノイズを含む点群データから安定した平面抽出を実現
- セマンティック情報を保持したままCAD変換

---

## 担当
- 点群処理ロジックの設計・実装
- CADデータ変換処理の開発
